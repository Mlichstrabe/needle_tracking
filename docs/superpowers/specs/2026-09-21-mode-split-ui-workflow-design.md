# 双模式入口与简化工作界面设计

日期：2026-09-21  
范围：`needle_tracking` 无配准训练程序的启动流程、两种模式的界面和姿态观察中的测距平移。本文定义设计，不记录已实现结果。

## 1. 目标与边界

启动后先显示小型模式选择窗口，由用户选择「姿态观察」或「穿刺模拟」。两种模式分别构建两栏工作页，复用现有 IMU、测距、几何计算与 3D 显示模块。主界面不再通过设备卡片里的下拉框切换模式。

程序仅用于固定影像上的训练显示，不进行 CT 与患者配准，也不根据此处的固定点给出临床入路建议。模式选择窗口保留「返回／退出」路径；从工作页返回时停止采集、释放两个串口、清除本次测距零点和模式状态，再允许进入另一模式。

## 2. 固定训练 CT、Entry 与 Target

穿刺模拟只使用当前 `config/dicom_last_path.json` 指向的固定 CT。已只读核查：该目录包含 729 张 DICOM，属于一个 SeriesInstanceUID，影像方向和图像尺寸一致。正常启动时自动加载这套 CT；配置路径缺失、序列身份不符或模型生成失败时，停止后续训练流程并显示原因。设置区允许重新定位**同一套** CT，不在正常流程中开放任意患者影像替换。

固定训练 Entry 在当前模型场景坐标中为约 `[12.00, 22.84, 97.81]` mm，位于右侧前部近头顶部的模型表面。沿用当前程序生成的默认 Target `[-15.00, 25.00, 30.00]` mm；当前加载结果下，Entry→Target 直线规划深度约 73.0 mm。入口点坐标须与该 CT 的序列身份及网格变换版本绑定。网格生成后核对入口点到表面的距离不超过 3 mm、规划深度与 73.0 mm 的差不超过 3 mm；否则报错，不静默使用另一表面点。

现有 Target 来自模型包围盒偏移，并非血肿分割结果。界面和日志统一称「固定训练 Entry／Target」及「模拟深度」。文献中前额入路可用于部分前部基底节出血，但文献不验证上述具体场景坐标，也不证明该直线路径的解剖安全性。

## 3. 启动与设备自动连接

`main.py` 先显示模式选择窗口，选择后才构建相应工作页。两个工作页都自动尝试连接 IMU 和 100 m 测距模块，且必须使用不同串口。

当前 Windows 检查到的两路设备均显示为 CH340，不能仅凭端口描述或 VID/PID 判定用途。自动连接应通过协议验证：先被动识别有效 IMU 帧，再验证另一候选端口的测距响应；存在多个匹配、没有匹配、串口占用或协议验证失败时，不猜测端口分配。此时对应连接项自动展开，允许人工绑定并保存设备标识供下次使用；下次仍需验证协议。连接状态与错误原因在主界面可见。

## 4. 姿态观察工作页

布局为左侧大幅 3D 针体、右侧紧凑操作区。右侧默认显示 IMU/测距连接状态、记录零点操作、平移模式状态和「进入／退出平移（Space）」按钮。原始距离、测得位移、画面已应用位移、与锁定针轴的夹角、欧拉角、四元数、校准和平滑参数全部放进折叠详情；阻断原因始终可见。无 CT、Entry、Target、对准 HUD 和穿刺完成进度。

姿态始终由 IMU 实时更新。测距平移仅改变训练场景中的相对位置，不构成空间定位。测距零点由操作者在针尖就位、读数稳定后记录。进入平移的条件为：IMU 与测距均连接、测距样本有效、零点有效、经零偏校正的陀螺仪角速度模长连续不超过暂定 3°/s 达 0.3 秒。按 Space 时锁定当前针轴作为平移方向；Space 只在该工作页生效，并有同等功能的可点击按钮。正向相对位移沿锁定的针尖推进方向应用：`d = 零点滤波距离 - 当前滤波距离`，`训练针尖位置 = 原点 + d × 锁定针轴单位向量`。按 Space 进入时立即采用当前有效 `d`。

平移模式在姿态偏差暂停时保持锁定，直到再次按 Space。模式内只有当前针轴相对锁定方向的夹角处于容差内、且测距有效时，才将最新相对深度应用到 3D 位置。暂定夹角**超过 10° 并持续 0.2 秒**后暂停位置更新；回到 **8°以内并持续 0.3 秒**后恢复，补到当前有效测距对应的位置。暂停期间针体姿态继续实时显示，画面位置保持上一次已应用值。轻微手抖不解除模式。3°/s、0.2/0.3 秒与 8°是实施初值，须以实机静置、转动和轴向移动数据验证并记录调整结果；10°是本轮确认的临时最大偏差。

测距异常、超时、跳变或零点丢失时，无论姿态如何都冻结位置。沿用现有测距面板的失效处理；零点被清除时自动结束本次平移锁定并进入「等待零点」，区别于姿态偏差造成的临时暂停。重新记录零点后须再按 Space，不能用旧零点自动恢复。界面分别保留测得位移与已应用位移，便于看出暂停期间的差额。

## 5. 穿刺模拟工作页

布局为左侧 3D CT/针体/训练路径，右侧固定显示对准引导、进针深度和暂停原因。CT、Entry、Target、IMU、测距的准备状态用紧凑状态区呈现；端口、原始遥测、校准、CT 可见性、路径引导等放入折叠详情。右侧仅在需要记录或重录零点时突出显示该操作，不保留六步流程条与重复状态标签。

进入工作页后自动加载固定 CT、设置固定 Entry 与现有默认 Target，并自动尝试连接两路设备。针尖就位且测距稳定后由操作者记录零点。之后沿用 `PunctureDepthController` 的训练规则：姿态误差进入 3°并保持 0.3 秒后允许测距驱动进针；超过 4°暂停；有效深度驱动进度和 3D 针尖；连续三个有效样本达到规划深度后完成。无效、超时、跳变或零点丢失必须阻断深度应用。这里不恢复定时自动进针。

固定 Entry/Target 只简化训练操作。CT 自动加载失败、入口点不匹配、任何一个设备连接失败或零点无效时，右侧明确显示当前阻断原因，不假装训练已经就绪。

## 6. 实施边界与验收

优先新增模式选择与两套工作页组合，复用现有 `core/device_manager.py`、`core/dicom_loader.py`、`core/imu_kinematics.py`、`core/puncture_depth_controller.py`、`ui/widgets/range_depth_panel.py` 和 3D 组件。避免复制串口解析、测距滤波或穿刺状态机。现有主窗口中的模式分支与不再显示的控件，在新工作页就绪后再定向清理。

可验收行为：

1. 启动先出现模式选择，选择姿态观察时不会加载 CT；返回后两路串口可被另一模式重新打开。
2. 选择穿刺模拟后自动加载指定 CT，固定 Entry/Target 和约 73.0 mm 规划深度可在 3D 中看到；CT 变化或缺失会阻断训练。
3. 两路串口自动识别且不互相占用；识别不确定时停在明确错误状态，人工绑定后可继续。
4. 姿态观察中，按 Space 前无测距平移；锁定后在允许角度内移动，超过 10°暂停但保持模式，回到范围并稳定后补到最新有效距离，再按 Space 退出。
5. 姿态观察中测距失效或零点丢失时 3D 位置冻结，重新记录零点和重新进入平移后才能继续。
6. 穿刺模拟仍由现有角度与有效测距驱动，完成判定和阻断状态不因 UI 简化而改变。

实机阈值和双串口自动识别须在目标机器上验证；离屏启动或单元测试不能代替硬件与目标 OpenGL 环境验收。
