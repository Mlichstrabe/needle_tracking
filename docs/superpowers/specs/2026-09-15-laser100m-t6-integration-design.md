# 100m 测距驱动进针与 T6 针体显示设计

日期：2026-09-15  
状态：设计已获用户确认，待规格复核  
范围：仅集成 100m 测距模块；暂不接入 STP-23L。

## 1. 目标

将当前主程序中的“按固定 10 秒自动推进虚拟针尖”改为“由 100m 模块测得的相对位移决定虚拟进针深度”，并在主程序 3D 视图中显示 T6 分段式 PLA 针体和外壳。

主程序仍是无配准训练程序：CT 模型、Entry 和 Target 定义训练坐标，IMU 提供姿态，100m 模块只提供沿光轴的一维位移/深度观测。该功能不控制真实机器人，也不宣称完成临床导航。

## 2. 已确认的硬件与 CAD 前提

### 2.1 串口

- JY901S IMU：独立串口，115200 baud，现有 `0x55`、11 字节帧协议。
- 100m 模块：独立串口，9600 baud，复用现有工具中的连续测量协议和 `Laser100mParser`。
- 两个设备必须使用两个不同的 COM 口；任一设备断开不应阻塞另一个设备的 UI。

### 2.2 T6 几何

模型目录：`output/cad_laser100m_T6_segmented_needle`。

- 三段针体：根部段、中段、针尖段；外露长度 200 mm。
- 针体主体约 Ø5 mm，根部最大约 Ø8.5 mm，针尖约 Ø4.4 mm。
- 100m 模块激光前端比针杆出口后置约 7 mm。
- 几何文件给出的 207 mm 初始距离和 57 mm 近端距离是几何估计，不是已验证的硬件测量范围。
- 运行时加载各单件 STL，不直接解析 STEP：下壳、上盖、传感器载架、三段针体和两根定位销。

### 2.3 姿态变换边界

当前 IMU 配置提供针轴方向标定，但没有完整的 CAD↔IMU 滚转标定。因此第一版：

- T6 模型的针轴跟随当前 IMU 针轴；
- CAD 的局部 +X 轴视为“针尖指向壳体”的方向，因此映射到场景中的 `-needle_direction`；
- 模型绕针轴的滚转使用稳定的固定姿态；
- 不把该版本的外壳滚转当作已完成的完整姿态标定。

模型锚点采用 T6 针尖局部坐标：

```text
cad_tip = [exit_x - exposed_length, 0, axis_z]
         = [-203, 0, 4.2] mm
```

每次姿态或针尖位置更新时，将所有 CAD 顶点按同一个刚体变换映射到场景：

```text
R(+X) = -needle_direction
world_vertex = world_tip + R @ (cad_vertex - cad_tip)
```

## 3. 推荐架构

### 3.1 新增核心模块

#### `core/laser100m_protocol.py`

从 `tools/laser100m_range_test.py` 抽取可复用逻辑：

- `Laser100mParser`；
- 设置频率和连续输出命令；
- 原始距离到补偿距离的分段补偿；
- 协议错误、设备错误、校验失败和丢弃字节统计；
- 一维测距有效性与滤波器。

工具脚本继续可独立运行，但不再成为主窗口的运行时依赖入口。

#### `core/laser100m_manager.py`

使用独立后台读取线程：

- 打开/关闭 100m 串口；
- 请求连续测量；
- 解析并发送 `range_received` 信号；
- 在读取错误或设备断开时发送错误/状态信号；
- 不直接触碰 PyQt UI。

每个测距样本至少包含：

```text
raw_distance_mm
corrected_distance_mm
filtered_distance_mm
status              # valid / invalid / target_lost / device_error
error_code
received_monotonic
bad_checksum_count
```

#### `core/laser100m_depth.py`

把“测距值”转换为“相对进针深度”，与串口和 UI 解耦：

```text
depth_mm = baseline_corrected_mm - current_filtered_distance_mm
depth_mm = clamp(depth_mm, 0, plan_depth_mm)
```

固定的 7 mm 激光后置距离不再额外加入公式，因为基准差分会抵消固定偏移。

## 4. 测距有效性与安全状态

控制链路固定为：

```text
协议解析
 → 数值/范围检查
 → 单帧跳变检查
 → 3 点中值
 → EMA(alpha=0.6)
 → 基准差分
 → 深度限制
 → 虚拟针尖
```

第一版应用范围默认约束为 30–500 mm，具体上下限进入配置，不把显示范围当成传感器物理量程。协议校验通过但明显异常的极大值也必须被标为无效。

规则：

1. 无有效基准时，不移动虚拟针尖。
2. 测距错误、超范围、异常跳变或目标丢失时，冻结最后一个“已应用深度”；不把旧值继续当作新深度，也不插值推进。
3. 恢复时要求连续 3 帧有效后才恢复深度更新。
4. 深度小于 0 时钳制为 0；超过 Entry→Target 规划距离时钳制到规划距离。
5. 传感器恢复后如果当前深度已经超过规划深度，显示“到达 Target”，但仍保留测距状态和后退能力。
6. 1–2 mm 的正常静态波动只通过测距滤波减小显示抖动，不能使用显示死区替代有效性判断。

## 5. 主窗口状态与流程

### 5.1 新增 UI

左栏新增“100m 测距”面板：

- COM 口选择和刷新；
- 连接/断开；
- 原始距离、补偿距离、滤波距离；
- 测距状态、错误码、数据年龄；
- “记录起始距离”按钮；
- `d0`、当前进针深度、规划深度和剩余深度。

IMU 与 100m 模块的连接状态独立显示。

### 5.2 基准距离

训练模式下，用户先加载 CT、选择 Entry 和 Target，并将 T6 针尖放在 Entry 位置。点击“记录起始距离”后，使用最近若干帧有效滤波距离的中值作为 `baseline_corrected_mm`。

只有在以下条件满足时允许记录：

- Entry 和 Target 已设置；
- 100m 模块已连接；
- 最近数据有效且未超时；
- 已获得足够的连续有效帧。

记录基准后，如果用户重选 Entry、Target 或切换工作模式，基准必须清除。

### 5.3 对准与深度的关系

- IMU 对准角度仍由现有 `alignment_timer` 计算。
- 100m 模块负责测得标量深度，不再由计时器累加深度。
- 未对准时保留并显示测得深度，但不把新深度应用到 CT 上的虚拟针尖；重新对准后再应用当前有效深度。
- 对准后，虚拟针尖沿 Entry→Target 规划方向移动：

```text
tip = Entry + target_direction_world * depth_mm
```

- 删除 `PUNCTURE_DURATION_S`、基于 `dt` 的推进和自动完成弹窗逻辑。
- 重置按钮清除当前深度并将虚拟针尖返回 Entry，但不自动重写新的 `d0`；用户需要重新明确记录基准。

### 6.1 资源加载

在 `GLVisualizationWidget` 中新增 T6 组件集合。优先加载这些 STL：

- `01_lower_chassis.stl`；
- `02_upper_cover.stl`；
- `03_sensor_carrier.stl`；
- `REF_04A_needle_root_segment.stl`；

### 6.2 显示更新

- T6 组件使用统一位置和姿态变换，不能只移动针杆而留下外壳。
- T6 针尖位置与当前虚拟针尖一致。
- T6 针轴与当前 IMU 方向一致。
- 继续保留 Entry、Target 和规划路径可视化。
- 现有抽象白色针线应被 T6 模型替代，或提供明确的调试显示开关，避免两套针体重叠造成误判。

## 8. 测试与验收

### 8.1 离线测试

- 解析数字帧、错误帧、坏校验和粘包/拆包；
- 异常极值、超范围和大跳变必须进入 invalid/target_lost；
- 滤波器不改变无效状态；
- 基准差分、后退、负深度钳制和规划深度钳制；
- 无基准或数据超时不移动虚拟针尖；
- T6 STL 全部加载并能完成刚体变换；
- 主窗口离屏初始化和关闭。

### 8.2 手动硬件验收

使用两个不同 COM 口：

1. 连接 IMU 和 100m 模块；
2. 在 Entry 位置记录基准；
3. 保持探针不动，确认深度不自行增加；
4. 平稳推进约 50、100、150 mm，比较测距深度与尺具/机械位移；
5. 暂时遮挡或移开靶面，确认深度冻结并显示无效；
6. 恢复有效目标，确认连续 3 帧后恢复；
7. 后退探针，确认虚拟针尖后退；
8. 到达规划深度后确认不会越过 Target。

离线通过不能代替上述硬件验收。尤其 T6 近端约 57 mm 的测量有效性、激光光轴与针轴平行度、PLA 分段胶接强度仍需实物验证。

## 9. 非目标

- 不接入 STP-23L；
- 不控制 UR5e 或其他机器人执行器；
- 不增加 CT↔患者配准；
- 不把一维测距直接解释为完整 CT 空间针尖观测；
- 不声称完成完整 CAD↔IMU 六自由度标定；
- 不用未经硬件验证的 57 mm 近端几何值作为传感器保证指标。
