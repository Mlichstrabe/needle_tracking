# 主程序实时工作区界面优化设计

## 已确认目标

在不改变 IMU、DICOM、100 m 测距协议和 3D 针体驱动逻辑的前提下，优化主窗口的信息层级。操作者应优先看到对准偏差、实时穿刺深度和设备状态，低频准备操作保持可访问但不持续占据屏幕。

## 布局

- 顶栏保留四步流程，状态区增加“测距”状态。
- 左栏改为可折叠准备区，顺序为 CT、IMU 设备、IMU 遥测；当前流程对应分区自动展开。
- 中栏继续使用现有 3D 视图，不改交互和几何数据。
- 右栏上半部固定显示对准 HUD 与 100 m 深度卡片，滚动时不得被选点和路径引导内容顶走。
- 右栏下半部单独滚动，保留现有 Entry/Target、模拟进针和姿态锁定功能。

## 组件行为

- 对准 HUD 增加独立的大角度数字，圆盘负责方向、数字负责偏差量。
- 深度卡片显示大号相对深度、实时距离、零点距离、连接/有效状态和紧凑操作按钮。
- 深度仍按“零点距离中值 − 当前原始距离”计算，不增加平滑，不写入 `gl_widget` 或模拟进针状态。
- 测距状态通过 Qt 信号同步到顶栏；状态分为未连接、连接中、正常、异常。
- 无效、超时或大跳变继续清除零点并要求重新记录，不能显示旧深度。

## 验收

1. 主程序可启动和关闭，无线程残留。
2. 顶栏同时显示 CT、Entry、Target、IMU、测距五个状态。
3. 右栏无需滚动即可看到对准 HUD 和完整深度主读数。
4. 左栏同时只展开当前最相关的准备分区。
5. 现有 Entry/Target、IMU、模拟进针信号连接保持不变。
6. 测距单元测试覆盖稳定零点、进针、回退、异常清零和状态信号。

## 明确不做

- 不接入 STP-23L。
- 不用测距值驱动 3D 针体或机器人控制。
- 不改变 100 m 串口命令、波特率、日志和有效性阈值。
- 不重构 DICOM、IMU 运动学或穿刺模拟业务。
