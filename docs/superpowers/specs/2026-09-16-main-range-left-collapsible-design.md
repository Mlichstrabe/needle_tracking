# 主窗口实时穿刺深度左移设计

日期：2026-09-16  
状态：用户已确认，已实施

## 目标

将实时穿刺深度模块从右侧固定实时区移到左侧现有 `PrepSidebar`，作为第 4 个可折叠分区，解除右侧测距卡片对 Entry 入针点选择区域的遮挡。

## 设计

- 左侧手风琴新增“4  实时穿刺深度 · 100m 测距”，默认收起。
- 展开后保留原有串口选择、连接/断开、实时距离、零点和相对深度显示。
- 右侧固定区只保留对准 HUD；Entry/Target 与路径引导继续在下方滚动区显示。
- 不改变测距串口协议、采集线程、零点差分、状态信号或与 IMU 的串口互斥逻辑。
- 不把测距值写入 3D 针尖、姿态或模拟进针状态。

## 验收

1. 主程序可启动，左侧显示第 4 个可折叠测距分区且默认收起。
2. 点击该分区后，原测距控件完整可用。
3. 右侧可直接看到 Entry/Target 选择区，不再被测距卡片压缩或覆盖。
4. 顶栏测距状态和窗口关闭时的采集线程清理保持正常。
