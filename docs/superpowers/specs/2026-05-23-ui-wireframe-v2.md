# 界面草图 v2 — 穿刺训练模式

**状态**: 已按方案 A 实施（2026-05-23）  
**日期**: 2026-05-23

## 现版问题（含截图反馈）

1. **白色割裂板**：`QScrollArea` 内部 `QWidget` 使用 Fusion 默认白底，深色 `QGroupBox` 浮在白板上。
2. **改动体感小**：仅换色/微调间距，布局仍是「三块 GroupBox 堆叠」，未建立医疗导航类产品的 **流程条 + 主 HUD** 结构。
3. **信息层级弱**：对准圆盘、角度读数、步骤说明权重接近，缺少「一眼看偏差」的焦点。

### 色板（product / 暗光 OR）

- 壳层 `#0a0e14` · 侧栏 `#101722` · 卡片 `#151d2a` · 描边 `#2a3d56`
- 主强调（链接/焦点）`#5ec8f0` · 成功 `#6ee7a0` · 警告 `#f0c14a` · 危险 `#ff7b7b`
- **禁止**侧栏出现 `#ffffff` 大块底（含 ScrollArea viewport）

### 分区职责

| 区域 | 内容 | 原则 |
|------|------|------|
| 顶栏 | 4 步状态机 + 连接/帧率 | 始终可见当前该做什么 |
| 左 准备坞 | DICOM / 串口 / IMU | 手风琴或折叠；IMU 四元数默认收起 |
| 中 视口 | GL 场景 | 占宽 ≥58%；工具条不抢侧栏 |
| 右 引导轨 | HUD + 步骤操作 | 圆盘最大；角度 24–32px tabular |

## 技术债（实施第 0 步）

```css
QScrollArea { background: transparent; border: none; }
QScrollArea > QWidget > QWidget { background: #101722; }  /* viewport 子 content */
```

并对 `scroll.setAutoFillBackground(False)`、`content.setObjectName("SidePanelContent")` 等在 QSS 中绑定。
