# 测距驱动穿刺状态机设计

日期：2026-09-16  
状态：核心行为已获用户确认，已完成初版实现，待硬件联调  
范围：无配准版 `needle_tracking` 主程序

## 1. 目标

移除当前“角度小于 3°后按固定 10 秒自动推进”的模拟进针逻辑。新的主流程为：

```text
导入 CT
→ 选择 Entry
→ 自动生成默认 Target 和规划深度
→ 连接 IMU 与 100 m 测距模块
→ 针尖位于 Entry 并手动记录测距零点
→ 姿态满足角度准入条件
→ 测距深度驱动穿刺进度与 3D 针尖
→ 到达规划深度并完成
```

角度只负责穿刺状态准入和暂停，不再产生任何位移。穿刺深度只来自测距模块。

## 2. 现实边界

- 100 m模块提供沿光轴的一维相对距离，不是 CT 空间中的三维针尖观测。
- 3D 针尖仍沿固定的 `Entry→Target` 规划方向显示；该显示是训练可视化，不构成 CT↔患者配准导航。
- 成立条件包括：测距模块与针体安装关系固定、参考靶面稳定、光轴关系已知且使用范围经过验证。
- 近距离有效性、不同靶面和不同环境光下的可靠性仍需硬件实验验证。

## 3. 状态机

### 3.1 状态

| 状态 | 含义 |
|---|---|
| `PREPARING` | CT、Entry、默认 Target 或规划深度尚未准备好 |
| `WAITING_DEVICES` | IMU 或测距模块未连接，或测距零点无效 |
| `ALIGNING` | 设备与零点有效，等待姿态进入准入阈值 |
| `PUNCTURING` | 姿态合格，使用有效测距深度驱动 UI 和 3D 针尖 |
| `ANGLE_PAUSED` | 穿刺期间姿态偏离；原始测距继续显示和记录，暂停应用到 3D |
| `RANGE_INVALID` | 测距超时、错误、越界、突跳或零点丢失；暂停应用深度和完成判定 |
| `COMPLETE` | 有效应用深度连续达到规划深度 |

### 3.2 角度规则

- 进入穿刺：角度误差 `<= 3.0°` 且连续保持 300 ms。
- 已进入穿刺后，当角度误差 `> 4.0°` 时进入 `ANGLE_PAUSED`。
- `ANGLE_PAUSED` 中重新满足 `<= 3.0°` 且连续保持 300 ms 后恢复 `PUNCTURING`。
- 3°进入、4°暂停形成滞回，避免阈值附近反复切换。
- `3.0° < 角度误差 <= 4.0°` 只是在已经进入 `PUNCTURING` 后的保持区间；处于 `ALIGNING` 或 `ANGLE_PAUSED` 时不能凭该区间进入或恢复穿刺。
- 暂停期间测距原始值和相对深度继续显示、记录，但不更新3D针尖，也不触发完成。

### 3.3 零点规则

- 用户在针尖位于 Entry、参考靶面稳定时手动点击“记录零点”。
- 零点必须来自当前最新且稳定的有效滤波距离；不自动使用首次读数。零点和后续距离必须使用同一条“3点中值 + EMA”数据链，禁止用原始零点减滤波距离。
- 测距模块停止、断开或重新连接，超过 0.5 秒无新数据，设备错误、物理越界或异常突跳时，零点失效。
- 零点失效后必须重新记录，状态不得直接恢复到 `PUNCTURING`。

## 4. 深度数据链

保留三类数据，不能相互覆盖：

```text
raw_distance_mm
  → 协议/错误码/物理范围/数据年龄/突跳检查
  → validated_distance_mm
  → 3 点中值
  → EMA(alpha=0.6)
  → filtered_distance_mm
  → baseline_filtered_mm（用户手动记录）
  → measured_depth_mm = baseline_filtered_mm - filtered_distance_mm
  → applied_depth_mm = clamp(measured_depth_mm, 0, plan_depth_mm)
```

- `raw_distance_mm`：原始设备距离，始终用于日志和故障追溯。
- 主距离读数可继续显示原始距离；穿刺深度、进度条、3D针尖和完成判定统一使用滤波距离计算，界面标签必须区分“原始距离”和“穿刺深度”。
- `measured_depth_mm`：可为负值，用于显示回退情况。
- `applied_depth_mm`：限制在 `[0, plan_depth_mm]`，用于进度条和3D针尖。
- 无效数据不得进入中值或 EMA，也不得被旧值伪装成新值。
- 无效期间可以保留最后一次3D位置，但界面必须明确显示暂停及数据无效；恢复前不得自动完成。

## 5. 完成判定

- 仅在 `PUNCTURING` 状态下执行完成判定。
- `applied_depth_mm >= plan_depth_mm` 连续 3 个有效测距样本后进入 `COMPLETE`。
- 单帧尖峰、角度暂停或测距无效不得触发完成。
- 完成后锁定最终应用深度，停止继续更新3D针尖；原始测距可继续显示。
- “重置穿刺”将深度、完成计数和状态清零，并要求重新记录测距零点。

## 6. 组件职责

### 6.1 `RangeDepthPanel`

继续负责串口交互和测距显示，并新增结构化信号：

```text
range_sample(raw_mm, filtered_mm, measured_depth_mm, age_s)
range_validity_changed(valid, reason)
baseline_changed(valid, baseline_mm)
```

面板不直接移动3D针尖，不决定穿刺完成。

### 6.2 `PunctureDepthController`（新增）

独立维护状态机，输入：

- 角度误差；
- IMU连接状态；
- 测距连接、有效性和零点状态；
- 测距深度；
- `Entry→Target` 规划深度。

输出事件：

```text
state_changed(state, reason)
depth_applied(measured_depth_mm, applied_depth_mm, plan_depth_mm)
completed(final_depth_mm)
```

该组件不依赖具体 Qt 控件，方法返回结构化事件，便于单元测试。

### 6.3 `MainWindow`

- `_update_alignment()` 只计算角度、更新 HUD 并把角度送入控制器。
- 删除固定 10 秒推进常量和基于 `dt` 的深度累加。
- 接收控制器的应用深度后调用现有 `_apply_tip_at_depth()`。
- 同步更新穿刺面板、工作流状态和完成提示。
- Entry重选、CT清除、设备断开和窗口关闭时重置控制器。

### 6.4 `PuncturePointPanel`

- 显示状态、测量深度、应用深度、规划深度和剩余深度。
- 明确区分“姿态暂停”“测距无效”“穿刺完成”。
- Target继续使用CT加载后的默认点，不开放用户自选。

## 7. UI行为

- 顶栏工作流调整为：`加载 CT → 选 Entry → 连接设备 → 姿态对准 → 测距进针 → 完成`。
- “连接设备”必须同时反映 IMU 和测距模块是否满足穿刺条件；二者仍使用独立串口。
- 角度合格但未记录零点时显示“请记录测距零点”，不得显示“可进针”。
- `ANGLE_PAUSED` 显示“姿态偏离，深度应用暂停”；测距数字仍实时变化。
- 从 `ANGLE_PAUSED` 恢复时，3D针尖直接同步到恢复时的当前有效应用深度，不生成虚假的匀速补间；若暂停期间深度发生变化，界面允许出现一次位置跳变并应在日志中记录恢复事件。
- `RANGE_INVALID` 显示具体原因，例如超时、设备错误、距离突跳或零点失效。
- `COMPLETE` 显示最终深度与规划深度，不使用单帧弹窗阻塞数据采集。

## 8. 异常和重置

| 事件 | 处理 |
|---|---|
| IMU断开 | 退出穿刺状态，停止3D深度应用 |
| 测距断开/超时 | 进入 `RANGE_INVALID`，零点失效 |
| 距离突跳 | 丢弃该样本，进入 `RANGE_INVALID`，要求重新记录零点 |
| 姿态偏离 | 进入 `ANGLE_PAUSED`，保留测距显示和最后3D位置 |
| Entry重选 | 清除规划深度、零点、已应用深度和完成状态 |
| CT清除 | 回到 `PREPARING` |
| 手动重置 | 深度归零、针尖回到Entry、要求重新记录零点 |

## 9. 测试

### 9.1 离线状态机测试

1. 无零点时，角度合格也不能进入 `PUNCTURING`。
2. 角度在3°附近抖动时不会反复切换。
3. 穿刺中角度超过4°进入暂停，深度信号继续接收但不应用。
4. 重新对准300 ms后恢复，并直接应用当前有效测距深度；暂停期间深度变化时只允许一次同步跳变，不做时间补间。
5. 超时、设备错误、越界和突跳不会更新3D，也不会完成。
6. 深度达到规划值不足3帧不能完成，连续3帧后完成一次。
7. 回退时测量深度下降，应用深度不低于0。

### 9.2 主窗口集成测试

1. 完成 CT、Entry、默认 Target、IMU 和测距连接。
2. 在 Entry 位置记录零点，确认深度约为0。
3. 角度未对准时移动测距靶面，确认3D针尖不推进。
4. 对准后推进已知位移，比较测距深度、UI进度与3D应用深度。
5. 中途偏离姿态，确认测距继续显示而3D暂停。
6. 恢复姿态，确认3D恢复到当前有效深度。
7. 遮挡靶面或制造超时，确认状态可见且不能完成。
8. 到达规划深度，确认连续3帧后只触发一次完成。

### 9.3 硬件验收指标

- 有效回复比例；
- 数据年龄和最大间断；
- 静态标准差及峰峰值；
- 已知位移下的 MAE、RMSE 和最大误差；
- 50–70 mm 近距离有效率；
- 角度暂停与恢复的状态切换延迟；
- 完成判定是否存在误触发。

## 10. 明确不做

- 不增加 CT↔患者配准。
- 不把一维测距解释为真实三维针尖位置。
- 不用未经有效性判断的原始值直接驱动3D或完成判定。
- 不保留固定10秒自动进针作为隐藏备用路径。
- 不在本次重构中接入STP-23L、UR5e或其他执行器。
