# 100 m测距模块近距离分段补偿设计

日期：2026-09-13

## 目标

仅修正100 m测距模块在近距离的系统性低估，同时保持70 mm及以上距离不变，并避免60 mm硬切换造成输出不连续。

## 补偿规则

以协议解析后的原始距离 `raw_mm` 为输入，计算每帧实际补偿量：

```text
raw_mm <= 60:
    applied_offset_mm = 2
60 < raw_mm < 70:
    applied_offset_mm = 2 * (70 - raw_mm) / 10
raw_mm >= 70:
    applied_offset_mm = 0

corrected_mm = raw_mm + applied_offset_mm
```

因此：

- 60 mm及以下完整补偿+2 mm；
- 60–70 mm之间从+2 mm线性衰减至0；
- 70 mm及以上保持原始值；
- 修正函数在60 mm和70 mm处连续，过渡段斜率为0.8，保持单调递增；
- 错误帧或无距离帧不参与补偿。

## 修改范围

- `tools/laser100m_live.py`：实时显示、曲线、对比记录采用分段补偿。
- `tools/laser100m_range_test.py`：静态实验的逐帧记录和补偿后统计采用相同规则。
- 不修改串口协议、频率配置、原始值解析、异常状态判断和主程序。
- 不在本次修改中加入中值滤波或EMA，避免同时改变多个实验变量。

## 参数和日志

保留命令行参数 `--offset-mm`，其含义调整为“60 mm及以下的最大补偿量”，默认值为2 mm；新增可配置的完整补偿终点60 mm和归零点70 mm。

每帧CSV同时保存：

- 原始距离；
- 修正距离；
- 本帧实际应用的补偿量。

设置JSON明确保存最大补偿量、完整补偿终点、归零点和分段公式，避免将其误读为全量程固定偏置。

## 验证

离线函数检查至少覆盖：无效值、50、60、65、70、100 mm。预期结果分别为：无效、52、62、66、70、100 mm。

修改后执行语法检查，并用57、60、65、70、100 mm样例验证连续性和70 mm以上不变。硬件重新采集属于后续独立实验，不把离线函数结果当作硬件精度结果。

## 边界

该补偿是依据当前有限距离实验提出的工程修正，不是厂家标定或临床精度证明。57–60 mm处仍需独立重复实验验证3%误差目标。
