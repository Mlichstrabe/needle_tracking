# 主窗口右栏测距卡片遮挡修复设计

日期：2026-09-16  
范围：仅修复主窗口右栏的 Qt 布局遮挡，不改变 100m 测距协议、数据有效性判断、零点差分或 3D 针体逻辑。

## 目标

在当前主窗口尺寸下，右栏的“对准 Target”和“实时穿刺深度”卡片中的文字、距离值、串口选择、连接/断开、记录零点及状态提示均不发生重叠；下方 Entry/Target 操作区仍保持可滚动访问。

## 方案

采用局部布局约束修复：

1. 为实时测距卡片明确合理的最小高度，并让内部控件按内容尺寸排列。
2. 调整右栏固定实时区与下方滚动区的伸缩策略，使实时卡片不被压缩到控件重叠，同时允许下方操作区缩小并滚动。
3. 保持原有控件顺序和信号连接，不新增测距功能，不把测距值写入 `gl_widget` 或模拟进针状态。

实际实现细节：测距卡片内部按钮、下拉框和状态区采用紧凑的垂直尺寸；对准 HUD 固定为 200 px；主窗口高度比例调整为可用屏幕高度的 90%，为实时区和下方滚动区保留明确的布局空间。

## 验收

- 主程序可启动，右栏无控件重叠或文字裁切。
- 测距卡片仍能列出 COM 口、连接/断开并显示实时距离。
- 记录零点后仍显示数值型相对深度。
- 关闭窗口后测距线程和串口正常释放。
- 不产生与本布局修复无关的代码或数据变更。

## 未处理范围

本次不调整测距误差、滤波、采样频率、深度算法或 3D 进针逻辑；不保证小于当前屏幕可用区域的极端窗口尺寸仍能同时展示所有固定实时内容。
