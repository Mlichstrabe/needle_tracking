# T10 一体针体：设计与验收

2026-09-16，用户明确要求取消分段、一次成型、略微增加直径和接触面积。

采用一个连续实心针体：200 mm外露、12 mm插入端，主体宽6 mm、根部最大宽8.5 mm，插入端外接圆直径4 mm。共用针轴下1 mm的纵向平面，主体剩余高度4 mm、平底宽5.66 mm。取消拼接孔、定位销和分段接缝。

针尖采用俯视半圆形的钝圆轮廓，向下延伸到统一底面。此次圆头不是轴对称球头；这一变化用于避免球头最前端从上层才出现。根部加固和插入端同步切平。

首选打印几何在同一个底面增加0.20 mm厚的连续侧边，宽16.5 mm、两端各延长4 mm，与针体融合为单实体。薄边可沿成品轮廓剪除。针体自身从z=0开始，薄边不将它抬高。T9的三个0.8 mm脚垫在脚之间留下悬空段，已弃用。

成品212 mm长，在180 mm见方平台上需要斜放；首选打印文件预旋转45°。实际打印区域、首层引导线等仍以用户切片软件为准。首层高度0.20 mm对应模型薄边厚度。

验收：成品和带边版本各为单个有效实体；STEP回读、STL水密；成品只有一个从针尖连续覆盖至插入端的共面底面；逐0.20 mm水平截面不得存在孤岛或孔洞；相邻层的横向增长不超过0.20 mm几何范围；原外壳不发生实体干涉；斜放包络留在180 mm平台内。

不将数字验收等同于实物成功。实际床面附着、热翘曲、剪边便利性与弯曲强度需实印验收。一次成型仍是细长件，因此打印后冷却、沿长边逐步取下。

复现命令：`uv run --python 3.12 --offline --with cadquery==2.6.1 --with trimesh --with matplotlib --with shapely --with networkx --with scipy python -X utf8 cad/laser100m_T10_onepiece.py`。

本机运行边界：CAD生成、STEP回读和截面检查均完成并写入输出后，CAD原生库在解释器退出阶段出现访问异常。仅导入CAD库也复现了异常。另用不加载CAD库的独立进程读取最终STL、逐层检查并校验ZIP；该进程的退出状态记录在交付报告中，避免将生成输出存在当作正常退出。
